What should installation show?

preflight version reports the candidate’s version and commit. The capability output should name preflight.discovery/v1, skill protocol 1, and the inspect, github, and compare features. If a command fails, resolve that prerequisite before continuing. See the installation guide.

Paste into the new Codex session
$preflight Before I edit, explain the sourced expectations relevant to my intended change, what evidence is available, what remains unchecked, and the next useful action. Ask me for my intended change if it is not already in this conversation.

Look for a useful answer, not a clean bill of health.

A good briefing connects your change to a source you can inspect, separates declarations from executed checks, and gives you a concrete next action. If no relevant expectation is found, an honest limited result is the right outcome.

GitHub inspection is optional. If you request it, existing authenticated gh access is needed. Missing access should leave the local briefing useful and the remote gap visible.

Paste into Codex with your printed observation path
$preflight Before handoff, compare fresh observations with the before.json path I provide. Explain the changed inputs or expectations that matter to my edit, any new or resolved findings, stale evidence, and the next action. Keep remote results separate from local edits. If the cause of a failure is unknown, say so. Ask for the saved path if it is not in this conversation.

Check whether the follow-up helps you decide what to inspect or verify next. A source edit can make earlier evidence stale. A removed workflow may explain missing configuration; it does not establish the cause of a test failure.

What is deliberately outside this walkthrough?

Discovery does not run arbitrary project tests, initialize trusted policy, change branch protection, or authorize a release. Existing isolated checking has separate prerequisites. The skill can suggest supported next actions and explain unsupported checks as gaps. Read the supported discovery boundaries.
